# ستاره — برنامه‌ی پاداش و عادت‌های خانواده

اپلیکیشن فارسی و راست‌چین برای پیگیری برنامه‌ی روزانه، تلاش‌های بچه‌ها و پاداش‌های خانواده. رابط کاربری برای موبایل و دسکتاپ طراحی شده و منوهای بالای صفحه و کناری قابل استفاده‌اند.

## اطلاعات آغازین این خانواده

- **محمد حسین** — تولد شمسی: ۲۶ فروردین ۱۳۹۴
- **محمد مهدی** — تولد شمسی: ۲ اسفند ۱۳۹۶
- **زهرا** — تولد شمسی: ۱۲ آبان ۱۴۰۵

برای فرزندان بزرگ‌تر، برنامه‌ی روزانه‌ی درس و گفت‌وگو، تمرین و حفظ زبان انگلیسی، حفظ قرآن و ورزش ساخته شده است. برای زهرا که نوزاد است برنامه‌ی درسی ساخته نمی‌شود. برنامه‌ها هر روز تکرار می‌شوند و والد می‌تواند آن‌ها را تغییر دهد، متوقف کند یا حذف کند.

## امکانات

- داشبورد امتیازها، کارهای منتظر تأیید و فعالیت‌های خانواده
- افزودن، ویرایش و حذف فرزندان و تاریخ تولد شمسی؛ محاسبه‌ی خودکار سن
- کارهای روزانه‌ی تکرارشونده و کارهای یک‌باره؛ والد با تأیید کار امتیاز می‌دهد
- ویرایش و حذف برنامه، کار و جایزه، جست‌وجو و مشاهده‌ی تاریخچه
- نرخ آغازین **هر امتیاز = ۱٬۰۰۰ تومان**؛ قابل تغییر در تنظیمات
- فروشگاه جایزه و نمایش ارزش تومانی امتیازها
- دریافت و بازیابی نسخه‌ی پشتیبان JSON
- ذخیره‌ی محلی اطلاعات در همان مرورگر/دستگاه؛ بدون نیاز به ورود یا اینترنت برای کارهای اصلی

> این برنامه برای ثبت و تأیید کارها با همراهی والد طراحی شده است. اطلاعات در مرورگر/دستگاه ذخیره می‌شوند و خودکار بین دستگاه‌ها همگام نمی‌شوند؛ برای انتقال، از بخش «تنظیمات و پشتیبان» نسخه‌ی پشتیبان بگیرید.

## اجرای وب

نیازمندی: Node.js 20 یا جدیدتر.

```bash
npm ci
npm run dev
```

سپس آدرس نمایش‌داده‌شده در ترمینال (معمولاً `http://localhost:5173`) را باز کنید.

ساخت نسخه‌ی وب:

```bash
npm run build
npm run preview
```

## ساخت APK

پوشه‌ی Android و Capacitor از قبل آماده‌اند. ساخت APK محلی نیازمند **JDK 21** و Android SDK است:

```bash
npm ci
npm run build
npx cap sync android
npm run android:build
```

فایل APK دیباگ در مسیر `android/app/build/outputs/apk/debug/app-debug.apk` ساخته می‌شود. نصب روی گوشی متصل به ADB:

```bash
adb install -r android/app/build/outputs/apk/debug/app-debug.apk
```

### ساخت خودکار در GitHub

گردش‌کار `.github/workflows/build-android.yml` با هر push روی شاخه‌های `main` و `arena/**`، با Pull Request به `main` یا به‌صورت دستی اجرا می‌شود. پس از اجرای موفق، از تب **Actions** وارد اجرای مربوطه شوید و artifact با نام `setareh-debug-apk` را دانلود کنید. APK داخل فایل ZIP است.
