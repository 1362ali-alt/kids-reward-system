# ستاره — سیستم پاداش خانواده

یک اپلیکیشن فارسی و راست‌چین برای کمک به خانواده‌ها در ایجاد عادت‌های خوب، تعریف کارهای روزانه، تأیید انجام کارها و تشویق بچه‌ها با ستاره و جایزه.

## امکانات

- داشبورد خانوادگی با نمای کلی ستاره‌ها، کارهای در انتظار و فعالیت‌های اخیر
- پروفایل فرزندان و موجودی جداگانه‌ی هر نفر
- تعریف کار، دسته‌بندی، تعیین فرزند و امتیاز؛ تأیید والد و افزودن خودکار ستاره‌ها
- فروشگاه جایزه با هزینه‌ی ستاره و ثبت دریافت برای هر فرزند
- گزارش تاریخچه‌ی امتیازها و جست‌وجو/فیلتر کارها
- طراحی واکنش‌گرا برای موبایل و دسکتاپ، منوی موبایل و ذخیره‌ی خودکار اطلاعات در مرورگر دستگاه
- پیکربندی Capacitor برای بسته‌بندی اندروید

> این نسخه‌ی اولیه داده‌ها را فقط در `localStorage` همان مرورگر/دستگاه نگه می‌دارد؛ همگام‌سازی ابری، ورود چندوالدی و پشتیبان‌گیری بین دستگاه‌ها هنوز پیاده‌سازی نشده‌اند. برای استفاده‌ی خانوادگی، ثبت کارها و جایزه‌ها با والد است و برنامه خودش کار کودک را تأیید نمی‌کند.

## اجرای محلی وب

نیازمندی: Node.js 20 یا جدیدتر.

```bash
npm install
npm run dev
```

برای نسخه‌ی نهایی وب:

```bash
npm run build
npm run preview
```

خروجی تولید در `dist/` ساخته می‌شود.

## ساخت APK اندروید

پروژه با Capacitor پیکربندی شده است. برای آماده‌سازی پلتفرم Android یک بار اجرا کنید:

```bash
npm install
npm run build
npx cap add android
npx cap sync android
```

سپس Android Studio و Android SDK یا JDK 17 + Android SDK و Gradle موردنیاز Capacitor را نصب و پیکربندی کنید. ساخت APK دیباگ:

```bash
npm run android:build
```

فایل خروجی در `android/app/build/outputs/apk/debug/app-debug.apk` خواهد بود. برای نصب روی دستگاه متصل به ADB:

```bash
adb install -r android/app/build/outputs/apk/debug/app-debug.apk
```

## وضعیت محیط توسعه

در محیطی که این مخزن در آن تکمیل شده، Node.js در دسترس است اما Java/JDK، Android SDK، Gradle و ADB نصب نیستند؛ در نتیجه APK را در همین محیط نمی‌توان ساخت یا روی شبیه‌ساز/دستگاه اجرا کرد. سورس وب و پیکربندی Android آماده‌اند؛ برای تولید و اجرای فایل APK، مراحل بالا را روی سیستمی با Android toolchain انجام دهید.
