# ستاره — برنامه‌ی پاداش و عادت‌های خانواده

اپلیکیشن فارسی و راست‌چین برای برنامه‌ی روزانه، تلاش‌ها و جایزه‌های خانواده. اطلاعات ابتدا روی دستگاه ذخیره می‌شوند؛ با اتصال به Firebase و ورود به حساب مشترک خانواده، تغییرات از طریق اینترنت بین گوشی‌ها زنده همگام می‌شوند.

## اطلاعات آغازین خانواده

- **محمد حسین** — تولد شمسی: ۲۶ فروردین ۱۳۹۴
- **محمد مهدی** — تولد شمسی: ۲ اسفند ۱۳۹۶
- **زهرا** — تولد شمسی: ۱۲ آبان ۱۴۰۵

برای دو فرزند بزرگ‌تر، برنامه‌ی روزانه‌ی درس و گفت‌وگو، تمرین و حفظ زبان انگلیسی، حفظ قرآن و ورزش ساخته شده است. برای زهرا که نوزاد است، برنامه‌ی درسی ساخته نمی‌شود.

## امکانات

- افزودن، ویرایش و حذف فرزند و تاریخ تولد شمسی؛ اعتبارسنجی روز واقعی تقویم، محاسبه‌ی خودکار سن، عکس پروفایل کم‌حجم، رنگ، علاقه‌مندی‌ها و یادداشت والدین
- کارهای یک‌باره و برنامه‌های تکرارشونده‌ی روزانه؛ ستاره فقط با تأیید والد افزوده می‌شود و تغییر روز، تاریخ کارهای قبلی را جابه‌جا نمی‌کند
- حفظ سابقه‌ی کارهای تأییدشده هنگام حذف برنامه؛ کار تکمیل‌شده قابل ویرایش یا حذف نیست تا موجودی با تاریخچه ناسازگار نشود
- ویرایش/توقف/حذف برنامه‌ها، کارها و جایزه‌ها؛ جست‌وجو و گزارش تاریخچه
- نرخ آغازین **هر ستاره = ۱٬۰۰۰ تومان**، قابل تغییر در تنظیمات؛ تبدیل مستقیم ستاره به پول نقد و ثبت پرداخت برای فرزند
- همگام‌سازی زنده‌ی خانواده بین گوشی‌ها با Firebase Authentication و Cloud Firestore
- خروجی و بازیابی نسخه‌ی پشتیبان JSON
- ذخیره‌ی محلی آفلاین؛ پس از بازگشت اینترنت، Firebase تغییرات را همگام می‌کند

## راه‌اندازی اولیه‌ی همگام‌سازی ابری

یک پروژه‌ی Firebase به حساب Google خودتان نیاز دارد؛ من نمی‌توانم به‌جای شما وارد حساب Google شوم یا پروژه‌ای در آن بسازم. راه‌اندازی فقط یک بار انجام می‌شود:

1. به [Firebase Console](https://console.firebase.google.com/) بروید و یک پروژه بسازید.
2. در **Build → Authentication → Sign-in method** گزینه‌ی **Email/Password** را فعال کنید.
3. در **Build → Firestore Database** پایگاه‌داده بسازید.
4. در **Project settings → General → Your apps** یک برنامه‌ی **Web** ثبت و تنظیمات Firebase را کپی کنید.
5. در Firestore، زبانه‌ی **Rules** را باز کنید، محتوای فایل `firestore.rules` را جای‌گذاری کنید و **Publish** را بزنید. این قواعد هر حساب را فقط به سند خانوادگی خودش محدود می‌کنند.
6. در برنامه، **تنظیمات → همگام‌سازی بین گوشی‌ها**، تنظیمات Web app را جای‌گذاری و ذخیره کنید. این شناسه‌های عمومی پروژه‌اند؛ رمز Google یا Firebase را در اینجا وارد نکنید. برای گوشی‌های دیگر هم این تنظیمات را وارد کنید؛ یا بعد از راه‌اندازی اول، فایل پشتیبان را بگیرید و در بقیه‌ی گوشی‌ها بازیابی کنید (فایل پشتیبان تنظیمات عمومی Firebase را هم دارد، اما رمز حساب را ندارد).
7. روی گوشی اول ایمیل و رمز مشترک خانواده را وارد و **ساخت حساب خانواده** را بزنید. روی گوشی‌های دیگر با همان ایمیل و رمز **ورود به حساب** را بزنید.

از این پس همه‌ی گوشی‌های واردشده به همان حساب، داده‌ی مشترکی می‌بینند. اگر لازم باشد، رمز حساب خانواده را فقط از راه امن بین اعضا به اشتراک بگذارید؛ هرگز آن را در چت یا مخزن GitHub ننویسید. بدون تنظیم Firebase، برنامه همچنان روی هر گوشی جداگانه و محلی کار می‌کند و همگام‌سازی انجام نمی‌شود.

## اجرای وب

نیازمندی: Node.js 20 یا جدیدتر.

```bash
npm ci
npm run dev
```

سپس آدرس نمایش‌داده‌شده (معمولاً `http://localhost:5173`) را باز کنید. برای ساخت نسخه‌ی وب:

```bash
npm run build
npm run preview
```

## ساخت APK اندروید

پروژه‌ی Capacitor از قبل آماده است. ساخت محلی به **JDK 21** و Android SDK نیاز دارد:

```bash
npm ci
npm run build
npx cap sync android
npm run android:build
```

APK دیباگ: `android/app/build/outputs/apk/debug/app-debug.apk`

ساخت خودکار نیز از تب **Actions** در GitHub در دسترس است؛ artifact موفق با نام `setareh-debug-apk` دانلود می‌شود. تنظیمات عمومی Firebase را می‌توان داخل خود برنامه وارد کرد؛ نیازی به رمز یا secret در GitHub Actions نیست.
